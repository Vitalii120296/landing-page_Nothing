Nothing Store - landing page of a modern electronics store

Landing page for a modern electronics brand inspired by **Nothing**.
The project focuses on clean UI, modern layout, and responsive design.

Live demo:
    - [DEMO LINK](https://vitalii120296.github.io/landing-page_Nothing/)


Design Reference:
    - [LINK](https://www.figma.com/file/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?type=design&node-id=6802-139&t=L7eKz5YKLN0m5WxR-0)


Technologies used:

- HTML5
- SCSS (modular structure)
- Responsive layout (Flexbox, Grid)
- BEM methodology
- Git & GitHub Pages

Features

- Responsive design (mobile / tablet / desktop)
- Clean and modern UI
- Smooth layout and visual hierarchy
- Pixel-perfect sections
- Optimized images
- Semantic HTML structure

Getting Started:

1. Clone the repository:
git clone https://github.com/Vitalii120296/landing-page_Nothing.git
cd landing-page_Nothing

2. Install dependencies:
npm install
# or
yarn install

3. Run the project locally:
npm start
# or
yarn start
